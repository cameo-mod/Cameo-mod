## Contract

This catalog converts every candidate in LEARN_CATALOG_SEED_2026-10-06.md into a fit-and-ship decision. Learning is offline developer/league tooling only. Reviewed committed YAML is loaded before a match and frozen. Runtime uses integer milli-values, percentages, ticks, cells, or enum arms. Keys are restricted to faction, doctrine/temperament, matchup, continuous map-feature vector, squad type, unit role, and game phase.
