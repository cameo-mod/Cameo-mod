## Finding 6 — the one idea worth keeping

Sol's `Anonymous` checks `parts[1]` only for two whitelisted arities and lets
`capture`/`frans`/`garrison_contest`/`veto` ids pass through verbatim. Real producers
(`EngineerBotModule.CaptureMissionId`, `FransCommandBidBotModule`, `CombatVetoBotModule`,
`GarrisonContestBotModule`, `SquadManagerBotModuleCA`, `BotMission.IdentityKey`) make
the actual grammar much richer:

- `frans:{auction.MissionId}` **nests a named mission id** — `frans:raid:Bravo:r4`
  passed through unchanged, leaking `Bravo`.
- `capture:<name>` / `capture:<name>:<type>` (malformed arity — the reviewer's
  explicit note) passed through unchanged.
- `garrison_contest:Bravo`, `veto:Bravo:900` malformed ids likewise.
- `secure:Bravo` (2-field), `defend_answer:{ParticipantKey}:{rally}`,
  `assist_answer:{RequesterId|#clientIdx}:{rally}` — Sol's code collapsed these to
  `unknown`; equivalent result under the port.

Ported (composition, not replacement): split on `:` and map **every** segment that
exactly equals a mapped identity (exact match — `Multi1` never shadows `Multi10`),
then emit only the shapes the audit's `mission_ok` accepts; anything else collapses
to `unknown`. This keeps Sol's closed-grammar contract — the emit side and the audit
side now mirror the same shapes — while names are neutralised at *any* position
before the shape check runs.

`seatReplacements` is built from **all** `world.Players`, so an unmapped alpha token
is provably not a player name and can stand in actor-type positions; unmapped tokens
in target positions still collapse to `unknown` (same as Sol).

Deltas vs Sol's version: `frans:raid:Bravo:r4` → `unknown` (was verbatim leak);
`capture:Bravo`, `capture:Bravo:oilb` → `unknown` (was verbatim leak);
`raid:Bravo:x` (bad region token) → `unknown` (was `raid:seat_13:x`, an
audit-illegal shape). Behaviour on all well-formed ids is unchanged.
