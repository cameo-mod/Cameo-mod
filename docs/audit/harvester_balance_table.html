Key Corrections from Engine Source
  • FullyLoadedSpeed is a percentage (Harvester.cs:284-287), not an absolute speed. When FullyLoadedSpeed=100 (inherited from ^Harvester in defaults.yaml), the harvester moves at 100% of its base Speed even when full — no slowdown. The engine default is 85%.
  • Load time includes +1 tick per bale for the actual harvest action (HarvestResource.cs:95-103). Each bale: 1 tick to harvest + BaleLoadDelay ticks wait. T_load = Cap × (BaleLoadDelay + 1).
  • Unload time includes +1 tick for the final IsEmpty check (Harvester.cs:176-202). First batch is immediate, then BaleUnloadDelay per batch. T_unload = ceil(Cap/BUA) × BaleUnloadDelay + 1.
  • Travel time uses terrain speed from the locomotor (Mobile.cs:756-761). Tracked=80%, foot=90%, chem=90%, swimsuit=90%, hover=90% on Clear terrain.
  • Movement is progress-based (Move.cs:471): each tick adds MovementSpeedForCell to progress; cell completes when progress ≥ 1024. T_travel = D × 1024 / eff_speed.
Key Finding: Asian Alliance Drone Miner vs Schwarzer Mond Noid Harvester

Asian Alliance refinery spawns 4 drone miners free; Schwarzer Mond refinery spawns 2 noid harvesters free.

Total income per refinery (per tick):

  • Asian Alliance: Cash/Tick × 4 drones
  • Schwarzer Mond: Cash/Tick × 2 noids

The noid's bottleneck: Cap=100 with BaleLoadDelay=5 means T_load = 100 × 6 = 600 ticks of stationary harvesting per cycle.
